# Команды, события и keymaps LazyVim

## 🔍 Как посмотреть текущий leader

### В Neovim:
```vim
:echo mapleader
:echo maplocalleader
```

### Через Lua:
```lua
:lua print("Leader:", vim.g.mapleader or "space")
:lua print("LocalLeader:", vim.g.maplocalleader or "backslash")
```

### Текущие значения:
- **Leader**: `<Space>` (пробел)
- **LocalLeader**: `\` (обратный слэш)

## 📋 Пользовательские команды LazyVim

Эти команды доступны даже с минимальной конфигурацией (без дополнительных плагинов):

### Основные команды

| Команда | Описание |
|---------|----------|
| `:Lazy` | Открыть менеджер плагинов lazy.nvim |
| `:LazyExtras` | Управление extras (дополнительными модулями LazyVim) |
| `:LazyHealth` | Загрузить все плагины и запустить `:checkhealth` |
| `:LazyFormat` | Форматировать текущий буфер |
| `:LazyFormatInfo` | Показать информацию о форматтерах для текущего буфера |
| `:LazyRoot` | Показать/изменить корневую директорию проекта |

### Использование команд

```vim
" Открыть менеджер плагинов
:Lazy

" Управление extras (выбрать picker, explorer, completion и т.д.)
:LazyExtras

" Проверить здоровье конфигурации
:LazyHealth

" Форматировать текущий файл
:LazyFormat

" Показать какие форматтеры доступны
:LazyFormatInfo

" Показать корневую директорию проекта
:LazyRoot
```

## ⌨️ Keymaps LazyVim (всегда активны)

Эти горячие клавиши работают даже с минимальной конфигурацией:

### Навигация по тексту

| Клавиша | Описание |
|---------|----------|
| `j` | Вниз (с учётом переносов строк) |
| `k` | Вверх (с учётом переносов строк) |
| `<Down>` | Вниз (с учётом переносов строк) |
| `<Up>` | Вверх (с учётом переносов строк) |

### Навигация по окнам

| Клавиша | Описание |
|---------|----------|
| `<C-h>` | Перейти в левое окно |
| `<C-j>` | Перейти в нижнее окно |
| `<C-k>` | Перейти в верхнее окно |
| `<C-l>` | Перейти в правое окно |
| `<C-Up>` | Увеличить высоту окна |
| `<C-Down>` | Уменьшить высоту окна |
| `<C-Left>` | Уменьшить ширину окна |
| `<C-Right>` | Увеличить ширину окна |

### Перемещение строк

| Клавиша | Режим | Описание |
|---------|-------|----------|
| `<A-j>` | Normal | Переместить строку вниз |
| `<A-k>` | Normal | Переместить строку вверх |
| `<A-j>` | Insert | Переместить строку вниз |
| `<A-k>` | Insert | Переместить строку вверх |
| `<A-j>` | Visual | Переместить выделенные строки вниз |
| `<A-k>` | Visual | Переместить выделенные строки вверх |

### Работа с буферами

| Клавиша | Описание |
|---------|----------|
| `<S-h>` | Предыдущий буфер |
| `<S-l>` | Следующий буфер |
| `[b` | Предыдущий буфер |
| `]b` | Следующий буфер |
| `<leader>bb` | Переключиться на другой буфер |
| `<leader>` | Переключиться на другой буфер (то же что bb) |
| `<leader>bd` | Удалить буфер |
| `<leader>bo` | Удалить все другие буферы |
| `<leader>bD` | Удалить буфер и окно |

### Очистка поиска

| Клавиша | Режим | Описание |
|---------|-------|----------|
| `<Esc>` | Normal/Insert/Select | Очистить подсветку поиска и остановить snippet |

### Сохранение файла

| Клавиша | Режим | Описание |
|---------|-------|----------|
| `<C-s>` | Normal/Insert/Visual/Select | Сохранить файл |

### Поиск

| Клавиша | Описание |
|---------|----------|
| `n` | Следующий результат поиска (с учётом направления) |
| `N` | Предыдущий результат поиска (с учётом направления) |

### Индентация

| Клавиша | Режим | Описание |
|---------|-------|----------|
| `<` | Visual | Уменьшить отступ |
| `>` | Visual | Увеличить отступ |

### Комментирование

| Клавиша | Описание |
|---------|----------|
| `gco` | Добавить комментарий ниже |
| `gcO` | Добавить комментарий выше |

### Управление

| Клавиша | Описание |
|---------|----------|
| `<leader>l` | Открыть Lazy (менеджер плагинов) |
| `<leader>fn` | Создать новый файл |
| `<leader>qq` | Выйти из всех окон |

### Окна

| Клавиша | Описание |
|---------|----------|
| `<leader>-` | Разделить окно горизонтально |
| `<leader>\|` | Разделить окно вертикально |
| `<leader>wd` | Закрыть окно |

### Вкладки (Tabs)

| Клавиша | Описание |
|---------|----------|
| `<leader><tab>l` | Последняя вкладка |
| `<leader><tab>o` | Закрыть другие вкладки |
| `<leader><tab>f` | Первая вкладка |
| `<leader><tab><tab>` | Новая вкладка |
| `<leader><tab>]` | Следующая вкладка |
| `<leader><tab>d` | Закрыть вкладку |
| `<leader><tab>[` | Предыдущая вкладка |

### Location List и Quickfix

| Клавиша | Описание |
|---------|----------|
| `<leader>xl` | Переключить Location List |
| `<leader>xq` | Переключить Quickfix List |
| `[q` | Предыдущий элемент Quickfix |
| `]q` | Следующий элемент Quickfix |

### Форматирование

| Клавиша | Режим | Описание |
|---------|-------|----------|
| `<leader>cf` | Normal/Visual | Форматировать |

### Диагностика

| Клавиша | Описание |
|---------|----------|
| `<leader>cd` | Показать диагностику строки |
| `]d` | Следующая диагностика |
| `[d` | Предыдущая диагностика |
| `]e` | Следующая ошибка |
| `[e` | Предыдущая ошибка |
| `]w` | Следующее предупреждение |
| `[w` | Предыдущее предупреждение |

### Redraw

| Клавиша | Описание |
|---------|----------|
| `<leader>ur` | Redraw / Очистить поиск / Обновить diff |

### Keywordprg

| Клавиша | Описание |
|---------|----------|
| `<leader>K` | Запустить keywordprg (обычно man или help) |

## 🔧 Что загружается даже с отключенными плагинами

Даже с минимальной конфигурацией (без дополнительных плагинов) LazyVim загружает:

### 1. Основные модули LazyVim

- `lazyvim.config.options` - базовые опции Neovim
- `lazyvim.config.keymaps` - стандартные keymaps
- `lazyvim.config.autocmds` - стандартные autocmds
- `lazyvim.util` - утилиты LazyVim

### 2. Глобальные переменные

```lua
vim.g.mapleader = " "              -- Leader клавиша
vim.g.maplocalleader = "\\"        -- LocalLeader клавиша
vim.g.autoformat = true            -- Автоформатирование
vim.g.lazyvim_picker = "auto"      -- Автовыбор picker
vim.g.lazyvim_cmp = "auto"        -- Автовыбор completion
vim.g.root_spec = {...}            -- Детекторы корневой директории
```

### 3. Базовые опции Neovim

Все опции из `lazyvim/config/options.lua`:
- `number`, `relativenumber` - номера строк
- `signcolumn` - левое поле
- `cursorline` - подсветка текущей строки
- `clipboard` - синхронизация с системным буфером
- И многие другие...

### 4. Все keymaps из `lazyvim/config/keymaps.lua`

Все перечисленные выше keymaps работают независимо от плагинов.

### 5. Все autocmds из `lazyvim/config/autocmds.lua`

Все перечисленные выше события активны.

### 6. Пользовательские команды

- `:Lazy`
- `:LazyExtras`
- `:LazyHealth`
- `:LazyFormat`
- `:LazyFormatInfo`
- `:LazyRoot`

### 7. Функции LazyVim

Доступны через `LazyVim.*`:
- `LazyVim.format()` - форматирование
- `LazyVim.root()` - определение корневой директории
- `LazyVim.pick()` - вызов picker
- И другие утилиты
