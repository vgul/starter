# Документация конфигурации Neovim (LazyVim)

Этот файл содержит описание всех настроек и команд в вашей конфигурации Neovim.

## Структура конфигурации

```
~/.config/nvim/
├── init.lua                    # Главный файл инициализации
├── lua/
│   ├── config/
│   │   ├── options.lua         # Настройки опций Neovim
│   │   ├── keymaps.lua         # Пользовательские горячие клавиши
│   │   ├── autocmds.lua        # Автоматические команды
│   │   └── lazy.lua            # Настройка lazy.nvim
│   └── plugins/
│       └── lazyvim.lua         # Настройки плагинов LazyVim
```

## 📄 init.lua

Главный файл инициализации. Загружается первым при запуске Neovim.

### Заглушка для Snacks

```lua
if not package.loaded["snacks"] then
  _G.Snacks = { ... }
end
```

**Что делает:**
- Создаёт заглушку для плагина `snacks.nvim`, который отключён
- Необходимо, т.к. LazyVim использует Snacks напрямую в некоторых местах
- Предотвращает ошибки при загрузке keymaps и других компонентов

**Компоненты заглушки:**
- `Snacks.keymap.set()` - обёртка для `vim.keymap.set()` с фильтрацией опций
- `Snacks.bufdelete()` - функция удаления буфера
- `Snacks.toggle` - таблица функций для переключения опций
- `Snacks.picker` - заглушки для picker функций
- Другие заглушки для git, terminal, debug функций

## ⚙️ config/options.lua

Настройки опций Neovim. Загружаются до инициализации lazy.nvim.

### Глобальные переменные LazyVim

```lua
vim.g.lazyvim_picker = "telescope"   -- Используемый picker (telescope/fzf)
vim.g.lazyvim_explorer = "neo-tree"  -- Используемый файловый менеджер
```

**Описание:**
- `lazyvim_picker` - какой picker использовать для поиска файлов/кода
  - `"telescope"` - Telescope (рекомендуется)
  - `"fzf"` - fzf-lua
  - `"auto"` - автоматический выбор
- `lazyvim_explorer` - какой explorer использовать
  - `"neo-tree"` - Neo-tree (рекомендуется)
  - `"snacks"` - snacks explorer (отключён)

### Настройки отображения

```lua
vim.opt.number = true              -- Показывать номера строк
vim.opt.relativenumber = false    -- Отключить относительные номера
```

**Описание:**
- `number` - показывает абсолютные номера строк слева
- `relativenumber` - показывает относительные номера (расстояние до курсора)
  - `true` - включить (полезно для навигации)
  - `false` - отключить (показывать только абсолютные номера)

### Настройки signcolumn (левое поле)

```lua
-- vim.opt.signcolumn = "no"      -- Полностью отключить signcolumn
-- vim.opt.statuscolumn = ""      -- Отключить кастомный statuscolumn
```

**Описание:**
- `signcolumn` - управляет отображением левого поля (для знаков, ошибок и т.д.)
  - `"yes"` - всегда показывать (по умолчанию в LazyVim)
  - `"auto"` - показывать только когда нужно
  - `"no"` - полностью отключить (минимальное левое поле)
- `statuscolumn` - кастомная колонка статуса LazyVim
  - `""` - отключить, использовать стандартный Neovim
  - `"%!v:lua.LazyVim.statuscolumn()"` - использовать кастомный (по умолчанию)

### Другие настройки

```lua
vim.opt.eventignore = { "SwapExists" }  -- Игнорировать события swap файлов
vim.opt.mouse = ""                      -- Отключить мышь
```

**Описание:**
- `eventignore` - список событий, которые Neovim будет игнорировать
  - `"SwapExists"` - игнорировать предупреждения о swap файлах
- `mouse` - управление поддержкой мыши
  - `""` - полностью отключить мышь
  - `"a"` - включить во всех режимах
  - `"n"` - только в normal режиме
  - `"v"` - только в visual режиме
  - `"i"` - только в insert режиме

## ⚡ config/lazy.lua

Настройка lazy.nvim - менеджера плагинов.

### Основные настройки

```lua
require("lazy").setup({
  spec = {
    { "LazyVim/LazyVim", import = "lazyvim.plugins" },
    { import = "plugins" },
  },
  defaults = {
    lazy = false,      -- Пользовательские плагины загружаются при старте
    version = false,  -- Использовать последний git commit
  },
})
```

**Описание:**
- `spec` - список плагинов для загрузки
  - `LazyVim/LazyVim` - основной плагин LazyVim
  - `import = "plugins"` - загрузить пользовательские плагины из `lua/plugins/`
- `defaults.lazy` - ленивая загрузка плагинов
  - `false` - пользовательские плагины загружаются при старте
  - `true` - все плагины загружаются лениво
- `defaults.version` - версионирование плагинов
  - `false` - использовать последний git commit
  - `"*"` - использовать последнюю стабильную версию

### Проверка обновлений

```lua
checker = {
  enabled = true,   -- Проверять обновления плагинов
  notify = false,   -- Не уведомлять об обновлениях
}
```

**Описание:**
- `enabled` - включить/выключить проверку обновлений
- `notify` - показывать уведомления об обновлениях

### Отключённые встроенные плагины

```lua
disabled_plugins = {
  "gzip",
  "tarPlugin",
  "tohtml",
  "tutor",
  "zipPlugin",
}
```

**Описание:**
- Список встроенных плагинов Neovim, которые отключены для улучшения производительности
- Эти плагины редко используются и их отключение ускоряет запуск

## ⌨️ config/keymaps.lua

Пользовательские горячие клавиши. Загружаются после загрузки всех плагинов.

**Текущее состояние:** Файл пуст, используются только стандартные keymaps LazyVim.

**Как добавить свои keymaps:**
```lua
local map = vim.keymap.set

-- Пример: создать keymap для нормального режима
map("n", "<leader>w", "<cmd>w<cr>", { desc = "Save file" })

-- Пример: создать keymap для visual режима
map("v", "<leader>y", '"+y', { desc = "Yank to clipboard" })
```

**Режимы:**
- `"n"` - normal режим
- `"i"` - insert режим
- `"v"` - visual режим
- `"x"` - visual режим (только выделение)
- `"t"` - terminal режим

## 🔄 config/autocmds.lua

Автоматические команды. Выполняются при определённых событиях.

**Текущее состояние:** Файл пуст, используются только стандартные autocmds LazyVim.

**Как добавить свои autocmds:**
```lua
-- Пример: автоматически форматировать при сохранении
vim.api.nvim_create_autocmd("BufWritePre", {
  pattern = "*.lua",
  callback = function()
    vim.lsp.buf.format()
  end,
})
```

**События:**
- `BufRead` - при открытии файла
- `BufWritePre` - перед сохранением
- `BufWritePost` - после сохранения
- `InsertEnter` - при входе в insert режим
- `InsertLeave` - при выходе из insert режима

## 🔌 plugins/lazyvim.lua

Настройки плагинов LazyVim.

### Отключение tokyonight

```lua
{
  "LazyVim/LazyVim",
  opts = {
    colorscheme = "default",  -- Использовать стандартную тему
  },
}
```

**Описание:**
- Переопределяет colorscheme по умолчанию
- `"default"` - стандартная тема Neovim
- Можно указать другую тему: `"habamax"`, `"desert"`, и т.д.
- Или использовать функцию: `colorscheme = function() vim.cmd.colorscheme("mytheme") end`

### Отключение snacks

```lua
{
  "folke/snacks.nvim",
  enabled = false,  -- Полностью отключить плагин
}
```

**Описание:**
- Отключает плагин `snacks.nvim`
- Плагин не будет загружаться и не займёт место

## 📚 Полезные команды Neovim

### Основные команды

| Команда | Описание |
|---------|----------|
| `:q` | Выйти из Neovim |
| `:q!` | Выйти без сохранения |
| `:w` | Сохранить файл |
| `:wq` | Сохранить и выйти |
| `:e <file>` | Открыть файл |
| `:help <topic>` | Открыть справку |

### Команды для опций

| Команда | Описание |
|---------|----------|
| `:set number` или `:set nu` | Включить номера строк |
| `:set nonumber` или `:set nonu` | Отключить номера строк |
| `:set relativenumber` или `:set rnu` | Включить относительные номера |
| `:set norelativenumber` или `:set nornu` | Отключить относительные номера |
| `:set signcolumn=no` | Отключить signcolumn |
| `:set signcolumn=auto` | Показывать signcolumn автоматически |
| `:set signcolumn=yes` | Всегда показывать signcolumn |

### Команды LazyVim

| Команда | Описание |
|---------|----------|
| `:Lazy` | Открыть менеджер плагинов |
| `:LazyExtras` | Управление extras (дополнительными модулями) |
| `:LazyHealth` | Проверить здоровье конфигурации |
| `:LazyFormat` | Форматировать текущий буфер |
| `:LazyFormatInfo` | Показать информацию о форматтерах |

## 🎨 Стандартные keymaps LazyVim

### Навигация по файлам

| Клавиша | Описание |
|---------|----------|
| `<leader>ff` | Найти файлы (в корне проекта) |
| `<leader>fF` | Найти файлы (в текущей директории) |
| `<leader>fr` | Недавние файлы |
| `<leader>fc` | Найти конфигурационные файлы |

### Навигация по буферам

| Клавиша | Описание |
|---------|----------|
| `<leader>bb` | Переключиться на другой буфер |
| `<leader>bd` | Удалить буфер |
| `<S-h>` | Предыдущий буфер |
| `<S-l>` | Следующий буфер |

### Поиск

| Клавиша | Описание |
|---------|----------|
| `<leader>/` | Grep (поиск в файлах) |
| `<leader>sg` | Grep в корне проекта |
| `<leader>sG` | Grep в текущей директории |
| `<leader>sw` | Поиск слова под курсором |

### Окна

| Клавиша | Описание |
|---------|----------|
| `<leader>-` | Разделить окно горизонтально |
| `<leader>\|` | Разделить окно вертикально |
| `<C-h/j/k/l>` | Перемещение между окнами |

## 🔧 Полезные советы

### Как изменить leader клавишу

В `config/options.lua` или `init.lua`:
```lua
vim.g.mapleader = " "  -- Пробел (по умолчанию)
-- или
vim.g.mapleader = ","  -- Запятая
```

### Как добавить свою тему

1. Установите плагин темы через `:LazyExtras` или добавьте в `plugins/`
2. В `plugins/lazyvim.lua`:
```lua
{
  "LazyVim/LazyVim",
  opts = {
    colorscheme = "mytheme",
  },
}
```

### Как отключить автоформатирование

В `config/options.lua`:
```lua
vim.g.autoformat = false  -- Отключить автоформатирование
```

### Как включить мышь

В `config/options.lua`:
```lua
vim.opt.mouse = "a"  -- Включить мышь во всех режимах
```
